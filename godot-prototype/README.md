# Word Cottage — маленький прототип у Godot

Окрема 2D-гра на Godot 4.7.2 Standard / GDScript, рендерер Compatibility. Портретний інтерфейс адаптується до телефону й залишається по центру широкого екрана. Ізометрична ілюстрація створює об’єм саду; живий паросток, квітка, вибір карток та анімації працюють у Godot.

Після публікації: https://olgaonufrak.github.io/word-cottage/godot-game/

## Що можна спробувати

1. Відкрити сад і натиснути «Вивчити 4 слова» або на грядку.
2. Познайомитися з `water`, `tea`, `coffee`, `milk`, побачити переклади й натиснути «Звук» для англійської вимови.
3. Знайти чотири пари «малюнок + слово». Можна починати з будь-якої колонки, змінювати вибір і виправляти помилки. До відповіді всі плитки однакові; правильна пара не стоїть в одному рядку. Колір показує результат лише після відповіді.
4. Отримати 4 листки й паросток після першого раунду, листя після другого, соняшник після третього. Наступні раунди — практика без повторних нагород; максимум 12 листків.
5. Повернутися в сад або пройти ще один раунд. Завершені раунди відновлюються після перезапуску на тому самому пристрої й адресі. Незавершений раунд починається заново.

Це невеликий зріз гри з одним розділом і чотирма словами. Решта словників, шість навчальних вправ, крамниця й мапа з презентації ще не перенесені. Нагороди тут демонструють розвиток саду, а не підтверджують довготривале засвоєння слів.

## Відкрити та змінити в Godot

Завантажте [офіційний Godot Standard](https://godotengine.org/download/windows/), у менеджері проєктів імпортуйте `project.godot`, натисніть F6 або F5. Для запуску з редактора export templates не потрібні. Достатньо штатних можливостей Godot, без плагінів і .NET.

Основні файли: `main.gd` — екрани та взаємодія; `scripts/lesson.gd` — слова, перемішування й перевірка пар; `scripts/progress.gd` — прогрес і збереження; `scripts/garden.gd` — жива рослина; `web/shell.html` — завантаження веб-гри й браузерне озвучення. Джерела ілюстрацій — у `ART.md`.

## Перевірки та веб-збірка

З кореня репозиторію, замініть шлях до Godot на свій:

```powershell
& 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path godot-prototype --editor --import
& 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path godot-prototype --script tests/run.gd
```

Перевірки охоплюють помилкові й правильні пари, перемішування, повторне натискання, межі нагород, відновлення збереження, переривання відкладеного зворотного зв’язку та висоту чотирьох екранів. Тестове збереження окреме, у `.godot/`; воно не змінює ігровий прогрес.

Встановіть export templates тієї самої версії через редактор, тоді:

```powershell
.\tools\build-godot.ps1 -Godot 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
```

Або вкажіть витягнутий із офіційного пакета **`web_nothreads_release.zip`**, а не багатопотоковий `web_release.zip`:

```powershell
.\tools\build-godot.ps1 -Godot 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe' -WebTemplate 'C:\Tools\Godot\web_nothreads_release.zip'
```

Скрипт імпортує ресурси, запускає тести, експортує `dist/godot-game/` та відновлює переносні налаштування export preset. Бінарний файл Godot, шаблони, `.godot/` і службові налаштування до Git не додаються. Готові `index.html`, `index.js`, `index.wasm`, `index.pck` та audio worklet файли потрібні разом. Веб-гра відкривається через HTTP(S), не подвійним кліком по HTML. Використано [однопотоковий Web export](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html), без вимоги спеціальних COOP/COEP заголовків на GitHub Pages.

## Дані та вимова

Чотири ID й переклади з `dist/stage1-data.js`, розділ `a1-drinks`, збережені. Веб-версія Godot зберігає власний `user://word-cottage-godot-prototype-v1.json` у браузерному сховищі рушія. Ключі навчального сайту `word-cottage-learned`, `word-cottage-personal-words` та історія не читаються й не змінюються. Прогрес між пристроями, веб-грою та редактором не синхронізується. Якщо браузер забороняє збереження, гра показує повідомлення.

У браузері вимова працює через `speechSynthesis`, у Windows — через доступні голоси Godot/операційної системи. Голоси залежать від пристрою; це не пряме підключення до Google Перекладача. Вимова не є умовою проходження вправи.
