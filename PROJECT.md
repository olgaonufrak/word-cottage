# Word Cottage — стан проєкту

Оновлено 21 жовтня 2026 року. Цей файл допомагає продовжувати роботу з різних чатів над одним проєктом. Останнє повідомлення користувачки та фактичні файли мають пріоритет над цим описом.

## Де працювати

Основна папка — корінь цього Git-репозиторію. Код зберігається локально й у GitHub; публікація відбувається через GitHub Pages.

Репозиторій: https://github.com/olgaonufrak/word-cottage

Адреса GitHub Pages: https://olgaonufrak.github.io/word-cottage/

GitHub CLI авторизований, репозиторій створено, `origin` указує на GitHub. Режим GitHub Pages — GitHub Actions (`workflow`), HTTPS увімкнено. Статус актуальної публікації перевіряється у вкладці Actions репозиторію.

`.github/workflows/pages.yml` запускає перевірки й публікує каталог `dist/` після push у `main`. Налаштування старого Sites hosting видалено за прямою вказівкою користувачки; надалі використовувати GitHub Pages.

Назва файлу публікації містить ID запуску та номер спроби: `github-pages-${{ github.run_id }}-${{ github.run_attempt }}`. Завантаження та публікація використовують ту саму назву, щоб повторний запуск не конфліктував із попередньою спробою.

## Що вже зроблено

- На телефоні вправи мають компактний вигляд: повернення до розділів, лічильник і меню в одному верхньому рядку; велика шапка, загальний прогрес та футер під час вправи приховані. Великий малюнок знову розташований над словом по центру: 136 × 136 px для одного та 112 × 112 px для кожного з пари, також на низьких екранах. Відступи менші, кнопки «Назад», «Підказка» й «Далі» в одному рядку, кнопки керування мають висоту щонайменше 44 px. На екранах до 600 px заввишки компактні відступи та аудіокнопки в один рядок дозволяють зберегти великий малюнок; видимі підписи аудіо короткі («слово», «приклад»), повні доступні назви — «Послухати слово» й «Послухати приклад». У складанні речення вибрані слова зникають з банку, залишаючись у відповіді. Меню й голосові функції доступні; після виходу до розділів повна шапка повертається. Вміст не обрізається: великий масштаб тексту чи довгий розгорнутий список слів за потреби дозволяє прокручування.

- У вправах є кнопка «← Назад» для повернення до попереднього завдання, зокрема між словами й кроками та з екрана завершення. На першому завданні вона неактивна. У межах заняття зберігаються чернетки відповідей, порядок варіантів, підказки, помилки, правильні відповіді, самоперевірка й складені речення. Перевірені відповіді залишаються заблокованими; повернення та повторний рух уперед не додають прогрес удруге. Історія поточного заняття зберігається в пам’яті вкладки, без зміни формату даних браузерного прогресу.

- У знайомстві зі словом є локальні ілюстрації для 1119 наявних карток (867 різних англійських записів). Повністю покриті меблі, частини тіла, числа, кольори, дні тижня та місяці; також є кімнати, побутова техніка, родина, професії, емоції, спорт, природа й наочні дії. Додано зрозумілі асоціації: time → годинник, idea → лампочка. `illustrations.js` враховує точний англійський запис та українське значення, зокрема table/desk, second (секунда/другий), short (короткий/невисокий), study (кабінет/дослідження). Для пар з / або — перевіряються значення складових. Використано фрагменти колажів користувачки, 466 локальних SVG Twemoji 14.0.2 та 209 SVG, створених для цього проєкту (зокрема композиція пор року з Twemoji). Картинки є лише під час знайомства; невідоме значення не отримує випадкової картинки чи порожнього блоку. Особисті слова з відповідним значенням також підтримуються. Джерела й ліцензії — `dist/illustrations-sources.txt`; браузерний прогрес та словник не змінюються.

- У шапці сайту є «Меню» → «Голосові функції». Вікно відкривається поверх поточного екрана й не скидає вправу чи вибір слів. Для англійської та української можна залишити автоматичний добір або вибрати доступний голос пристрою, перевірити звичайну й повільну вимову ×0,35 та зупинити озвучення. Вибір діє для всіх слів і прикладів та зберігається окремо в `word-cottage-voices`; прогрес і особисті слова не змінюються. Якщо обраного голосу немає, використовується автоматичний добір. Перелік оновлюється після завантаження голосів браузером. За проханням користувачки 19 голосів із фото (Albert, Bad News, Bahh, Bells, Boing, Bubbles, Cellos, Wobble, Fred, Good News, Hysterical, Junior, Kathy, Organ, Superstar, Ralph, Trinoids, Whisper, Zarvox) виключено зі списку та озвучення. Фільтр враховує українські назви iOS і системні ідентифікатори Apple. Раніше збережений виключений голос замінюється автоматичним добором дозволеного голосу; за його відсутності використовується доступний словниковий запис.

- За проханням користувачки з головної прибрані декоративна зірочка біля «З чого почнемо сьогодні?» та дві стрілки біля «Відкрити» у групах. Залишені текстові підписи.

- Кадрування всіх квадратних ілюстрацій виправлене після поміченої смужки сусідньої картинки під книжками. Для кожного з чотирьох колажів виміряні фактичні нерівномірні межі рядків і стовпців. cottageCrop відступає на 8 пікселів усередину малюнка та обирає центральний квадрат; один механізм використовується для всіх 100 фрагментів, галереї, обкладинок груп і етапів, заголовків та мініатюр. Ілюстрація заповнює внутрішню площу квадрата; декоративна рамка збережена.

- За новим уточненням користувачки обкладинки двох груп, чотирьох етапів і заголовків усередині етапів квадратні (1:1) на всіх ширинах. Замість вузьких смуг колажу використані окремі малюнки: будиночок і книжки для груп; полуниці, ліхтар, книжки та лебідь для етапів. Обкладинки розташовані біля тексту й не розтягуються за висотою картки. Мініатюри тематичних і початкових розділів також залишаються квадратними.

- Оформлення оновлено новими чотирма фото користувачки від 18 жовтня (кожне зі сіткою 5×5): світлий паперовий фон, оливкові кнопки, ілюстровані обкладинки двох груп і мінігалерея на головній. За уточненням користувачки у мінігалереї показані чотири окремі малюнки з колажів: будиночок, чашка чаю, зайчик і лаванда, по одному з кожного фото. Кадрування головної та мініатюр адаптоване до сітки 5×5 й фактичного розміру нових фото. Усі обкладинки груп, етапів та бічна ілюстрація також використовують нові зображення. Порядок файлів відповідає попереднім палітрам: cottage-1 — нове Фото 4, cottage-2 — Фото 1, cottage-3 — Фото 2, cottage-4 — Фото 3. Параметр зображень ?v=20261018 оновлює браузерний кеш. Етапи 1–4 використовують відповідно `dist/images/cottage-1.jpg`–`cottage-4.jpg`; тематичні картки мають фрагменти свого зображення. Початкові розділи використовують мотиви з усіх чотирьох фото. Оригінали збережено локально; дизайн адаптований до вузького екрана. Головна, етапи, початкова основа та списки слів при переході відкриваються з початку сторінки. На екранах до 480 px картки початкових розділів розташовані в одну колонку для довгих українських назв. Навчальні ID та браузерні сховища не змінені.

- За останнім уточненням користувачки повернуто початковий темний колір `var(--ink)` для ключових слів і речень. У кроках 2–6 та відкритих підказках збережено клас `exercise-focus` із курсивом Georgia, як напис «word cottage» у футері, та вагою 400. Так само оформлені звичайні картки й слова при відборі свайпами. Екран знайомства повернуто до попереднього вигляду: головне англійське слово — прямий Georgia, український переклад — звичайний Arial; класу `exercise-focus` там немає.
- У вправі «Обери англійською» помилково натиснутий варіант має м’який червоний фон, рамку й текст та лишається вимкненим. Видимого повідомлення «Спробуй ще раз» немає; для зчитувачів екрана є позначка помилки й приховане повідомлення. Інші варіанти залишаються доступними. Після правильної відповіді обраний варіант має стійкий світло-зелений фон та оливкову рамку, «Далі» стає доступною; повідомлення про успіх оголошується зчитувачами екрана. З новим завданням обидва підсвічування очищаються.

- Новий основний режим «Вправи у 6 кроків» за фото користувачки: знайомство з перекладом і простим прикладом, впізнавання серед відповідей, самостійне написання, пропуск із перекладом-підказкою, складання з готових слів, власне речення. Кожний крок охоплює весь обраний набір, потім починається наступний. Позначені слова одразу запускаються у вправах без вибору режиму у списку. Звичайні картки з обома напрямками можна обрати на екрані кількості без позначок. Фільтр «Лише невивчені» обмежує набір ще до свайпів.
- За уточненням користувачки екрани навчання містять тільки вправу: слово й приклад або коротку умову, відповідь, аудіо та кнопки. Назви кроків, схема шести кроків, пояснення мети, навчальні блоки й інструкції переходу прибрані. Загальний прогрес показується числами; кнопка переходу — «Далі».
- Біля аудіо слова й прикладу у знайомстві є компактні кнопки «×0,35» (повільніше за попередні «×0,5»). `speak` приймає четвертий параметр швидкості: `.35` зменшує звичайний темп синтезу `.95` до 35%, а швидкість резервного словникового запису — до `.35` зі збереженням висоти голосу. Звичайні кнопки відтворюють зі стандартним темпом; нове натискання зупиняє попереднє аудіо та скасовує очікування голосу. Інші виклики озвучення збережено зі стандартним темпом.
- `context-data.js` містить прості контекстні приклади для всіх 3030 наявних карток, прив’язані до стабільних ID, та офлайн-переклади всіх слів у цих прикладах. `I say “…”` прибрано. Для пар є приклади кожного слова, для різних значень — окремі контексти. `lesson-data.js` добирає приклад і фактичну форму пропуску; власне речення може використати будь-яке зі слів пари. Нові особисті слова перевикористовують приклад із відповідним значенням або отримують коротку конструкцію за українським перекладом; довільний особистий переклад не гарантує правильного визначення частини мови. Надалі приклади слід редагувати в базі, перевіряючи граматику й переклад.
- Кожне слово в прикладі — доступна з клавіатури кнопка. Натискання показує переклад під реченням і не змінює крок, відповідь чи прогрес. Це працює у знайомстві, відкритій підказці та видимих частинах речення з пропуском. У складанні речення вибір чи прибирання слова також показує його переклад. Невідомі складові особистих прикладів перекладаються через наявний MyMemory із кешем у пам’яті й захистом від запізнілих відповідей після переходу.
- `exercises.js` перевіряє варіант, написання, пропуск і порядок слів; неправильна чи порожня відповідь не відкриває наступне завдання. Є підказки, повторні спроби й англійське аудіо. Власне речення обмежене лексикою, показаною в поточному занятті: тільки знайомі конструкції перевіряються автоматично, решта потребують явної самоперевірки й залишаються для повторення. Це локальна перевірка зразків, а не універсальна перевірка англійської граматики. Слово зараховується в `word-cottage-learned` лише після виконання шостого кроку з розпізнаною конструкцією; самоперевірка не додає нове вивчене слово. Старі ID і формати сховищ збережено.

- `pronunciation.js` містить офлайн-транскрипції IPA для всіх 3030 карток (2474 унікальні англійські записи), переважно General American. У фразах поєднано словникові повні форми слів. Вимову омографів звірено зі значенням; джерела, зміни й ліцензії — у `dist/pronunciation-sources.txt`. Транскрипція показується під англійським словом у повних і вивчених списках, свайпах, англійській стороні звичайних карток, знайомстві, варіантах відповіді та відкритій підказці. У пригадуванні без підказки й на українській стороні картки відповіді через IPA не розкриваються. Збережені IPA особистих слів мають пріоритет; для відсутніх є онлайн-пошук із кешем у пам’яті, без зміни браузерного прогресу чи особистого словника.
- Стартова сторінка: «Слова на кожен день» і «Основа для початківця».
- Початкова основа: 400 карток — по 100 іменників, дієслів, прикметників та найуживаніших слів. Є змішаний набір, пошук, особисті та вивчені слова.
- Етап 1: 29 розділів, 649 карток, зокрема короткі фрази та антоніми.
- Етап 2: 29 розділів у порядку користувацького списку, 781 картка. Теми від Prepositions і Conjunctions до Irregular Verbs, Adverbs та Everyday Expressions.
- Етап 3: 25 розділів у порядку користувацького списку, по 30 карток у кожному — разом 750. Теми від Personality Traits і Health and Medicine до Phrasal Verbs та Problems and Solutions: побут, подорожі, культура, технології, безпека та природа. У кожної картки є український переклад; навчання, пошук і прогрес працюють так само, як в Етапах 1 і 2.
- Етап 4: 15 тем у порядку користувацького списку, від Office до Successes and Failures, по 30 карток — разом 450. Під кожною англійською назвою є український підпис малими літерами; у кожної картки є український переклад. Synonyms містить пари близьких за значенням слів з уточненнями стилю або інтенсивності. Усі теми використовують повний список, англійське аудіо, ручний вибір, кількість, свайпи, навчання, повторення та прогрес.
- Разом у файлах 3030 навчальних карток. Повторення слова у різних темах допускається; кожна картка має свій ID. Особисті слова додаються до цієї кількості в конкретному браузері.
- Перед вибором кількості показується весь список розділу з перекладами, чекбоксами та кнопкою ♫ лише англійською. Є «Обрати всі», «Зняти вибір» та нижня кнопка «Почати вчити».
- Якщо слова позначені галочками, «Почати вчити» одразу запускає весь позначений набір без питання про кількість та без повторного відбору свайпами. Рядок «Навчання» з вибором режиму прибрано з нижньої панелі списку: залишено кількість слів та кнопку «Почати вчити», позначений набір одразу запускається у вправах у 6 кроків. Порядок слів відповідає списку. Це працює в усіх етапах, особистому словнику та змішаному наборі. Без позначок кількість обирається через −/+, 5/10/20, далі свайпи з усього розділу.
- Повернення зі списку, навчання й результатів веде до відповідного етапу.
- Пошук англійською та українською по всіх етапах, основі та особистих словах. Онлайн-переклад MyMemory, транскрипція й доступні записи Wiktionary. Невідоме слово можна додати вручну.
- Озвучення через голоси пристрою: перевага Google та природних голосів відповідної мови. Це не пряме підключення до Google Перекладача. За відсутності голосу використовуються доступні словникові записи; їх може не бути.
- Локально встановлений шрифт Caveat для маленького зеленого заголовка онлайн-словника.

## Будова

`dist/index.html` підключає скрипти у важливому порядку: `data.js`, `stage1-data.js`, `stage2-data.js`, `stage3-data.js`, `stage4-data.js`, `search.js`, `pronunciation.js`, `context-data.js`, `illustrations.js`, `lesson-data.js`, `exercises.js`, `app.js`. Особисті слова відновлюються перед прогресом.

`app.js` має параметр версії `?v=20261018-filtered-voices`; `illustrations.js`, `exercises.js` та CSS — `?v=20261021-vocabulary-images`. Після наступної зміни потрібно оновити відповідний параметр `v`; інакше браузер може тимчасово використовувати попередню копію з кешу.

`stageOneSections`, `stageTwoSections`, `stageThreeSections` і `stageFourSections` містять метадані та рядки `english|український переклад`. Усі чотири етапи заповнені. Порожні рядки Етапу 4 не створюють карток. Скрипт `stage4-data.js` підключений із параметром `?v=20261009-vocabulary`, щоб браузер завантажував заповнений словник після попередньої версії з порожніми темами. На завантаженні вони доповнюють спільні `categories` і `words`. ID тематичної картки: ID розділу + англійський текст у нижньому регістрі через encodeURIComponent. Не змінюй ID вже вивчених карток.

Навігація й навчання в `app.js`: `landing`, `showDailyStages`, `showDailyStage`, `showBasics`, `showSectionWords`, `chooseAmount`, `suggestWords`, `start`, `showLearned`. `dailyStages` пов’язує кожний етап зі словником; кнопка відкриття з’являється для етапів із темами. `dailyView` зберігає поточний етап, а `dailyStageNumber()` визначає номер для повернення та підписів кнопок. `basicCategories()` виключає категорії етапів із меню старої основи.

Стан прогресу — `word-cottage-learned`, особистий словник — `word-cottage-personal-words` у localStorage. Локальна копія, онлайн-копія, інший браузер і телефон мають окремі сховища; синхронізації немає. Збереження папки не експортує браузерний прогрес.

## Перевірки

У `checks/` є перевірки Етапів 1–4, повного списку, ручного вибору, свайпів і підбору голосів. `verify-stage-three.cjs` перевіряє порядок 25 тем, усі 750 карток, навігацію Етапу 3, вибір слів, аудіо, обидва напрямки навчання, повторення, пошук і збереження особистих слів та прогресу. `verify-stage-four.cjs` перевіряє порядок 15 тем, 450 перекладених карток, аудіо й ручний вибір у кожному списку, кількість, свайпи, обидва напрямки, повторення, пошук та збереження прогресу. `verify-section-list.cjs` також перевіряє повернення зі списків Етапу 4 і порожній особистий словник без запуску навчання. Усі одинадцять перевірок запускаються також у GitHub Actions перед публікацією. verify-six-step-learning.cjs перевіряє шість кроків, розв’язуваність усіх карток, помилки, самоперевірку, фільтр невивчених і відкладене збереження прогресу. `verify-transcription.cjs` перевіряє офлайн-покриття всіх карток, омографи, списки та навчання без розкриття відповіді через IPA, особисті слова, безпеку відображення й асинхронного пошуку. verify-context-examples.cjs перевіряє всі приклади, офлайн-переклади їхніх складових, натискання без зміни прогресу, пари й асинхронні відповіді для особистих слів. Запуск із кореня проєкту описано в `checks/README.md`. Перевірки використовують модель DOM і голосів; фактичне звучання залежить від пристрою.

Оглянуто ширину 390 px без горизонтального переповнення; кнопка аудіо працює без помилок у консолі, фактичне звучання на телефоні окремо не перевірялося. Варіанти впізнавання добираються насамперед із поточного заняття та тієї самої теми.
