# Перевірки Word Cottage

Потрібен Node.js; додаткові пакети не потрібні. Запускайте команди з кореня папки Word Cottage:

```text
node checks/verify-stage-one.cjs
node checks/verify-stage-two.cjs
node checks/verify-stage-three.cjs
node checks/verify-stage-four.cjs
node checks/verify-section-list.cjs
node checks/verify-swipe-selection.cjs
node checks/verify-natural-voice.cjs
node checks/verify-six-step-learning.cjs
node checks/verify-exercise-back.cjs
node checks/verify-transcription.cjs
node checks/verify-context-examples.cjs
node checks/verify-illustrations.cjs
```

Перевірки охоплюють словники, навігацію, повні списки й ручний вибір слів, обмеження кількості, свайпи, навчання, відновлення прогресу та підбір голосів. Це перевірка логіки через імітацію DOM і браузерних API, а не перевірка зовнішнього вигляду чи реального звучання аудіо.

`verify-stage-four.cjs` перевіряє всі 15 тем і 450 карток Етапу 4, вибір слів, аудіо, свайпи, обидва напрямки навчання, повторення, пошук і збереження прогресу. `verify-section-list.cjs` перевіряє також повернення зі списків Етапу 4 і порожній особистий словник без запуску навчання.

`verify-section-list.cjs` також перевіряє запуск усіх позначених слів одразу у вправах без вибору режиму, кількості та свайпів, вибір усіх слів, очищення вибору, особисті та змішані набори. Без позначок перевіряються кількість і свайпи.

`fixture.cjs` — спільна модель браузера для цих перевірок; окремо її запускати не потрібно.

`verify-exercise-back.cjs` перевіряє повернення між словами й кроками та з екрана завершення, неактивну кнопку на першому завданні, відновлення варіантів, помилок, підказок, чернеток, складених речень і самоперевірки, блокування перевірених відповідей та відсутність повторного запису прогресу.

`verify-natural-voice.cjs` перевіряє стандартний і повільний темп ×0,35, збереження швидкості при відкладеному завантаженні голосів та помилках синтезу, швидкість резервного аудіозапису й збереження висоти голосу. `verify-six-step-learning.cjs` також перевіряє кнопки «×0,35» для слова та прикладу, повернення до звичайного темпу й незмінність прогресу після прослуховування.

`verify-six-step-learning.cjs` перевіряє новий основний режим: ручний вибір → одразу усі шість кроків, помилкові та порожні відповіді, підказки, написання слова, пропуск, складання з окремих кнопок, власні речення, чесну самоперевірку без автоматичного зарахування, повторення, аудіо, фільтр невивчених, безпечне відображення власних слів і відновлення прогресу. Перевіряється наявність розв’язуваного прикладу для кожної картки, включно з парами та особистими словами. Попередні перевірки явно обирають режим звичайних карток для перевірки обох напрямків і самооцінювання.

`verify-transcription.cjs` перевіряє IPA усіх 3030 карток без інтернету, відповідність значенням омографів, списки й навчальні екрани, відсутність підказки-відповіді під час пригадування, збереження прогресу та особистих слів, безпечне відображення й асинхронне завантаження для нових особистих слів.

`verify-context-examples.cjs` перевіряє приклади всіх 3030 карток, переклади всіх їхніх складових без мережі, значення омографів, обидва слова пар, фактичну форму пропуску, натискання й повторне натискання без зміни вправи, переклад у складанні речення, відсутність витоку відповіді, безпечне відображення та запізнілі онлайн-відповіді для особистих слів.

`verify-natural-voice.cjs` також перевіряє вибір голосу кожної мови, його відновлення після перезавантаження, автоматичний добір за відсутності обраного голосу, звичайні й повільні проби, зупинку озвучення, недоступність синтезу та відкриття вікна без втрати поточного заняття чи зміни наявних ключів збереження.

Перевірка голосів також виключає всі 19 голосів із фото користувачки за англійськими й українськими назвами та Apple URI. Перевіряються приховування в меню, ігнорування раніше збереженого виключеного голосу, збереження звичайних голосів, резервний аудіозапис та відсутність запуску виключеного голосу, коли інших голосів немає.

`verify-illustrations.cjs` перевіряє добір за значенням, стіл і годинник для часу, різні значення second/short/study, пари з — та /, повноту меблів, частин тіла, чисел, календаря і кольорів, особисті слова, наявність локальних SVG та ліцензії, межі кадрування наявних фото, відсутність зображень у наступних кроках, безпечне відображення та незмінність збережених даних. Оновлення стилю зберігає всі 1119 зображених карток: перевіряються 597 використаних SVG і повний набір 675 деталізованих файлів у `images/vocabulary-folk/`, включно з 200 предметними накладками та окремою версією кешу зображень, безпечні внутрішні посилання фактур і кадрування, незмінні числа та календарні підписи, геометрія стрілок, календарних позначок і частин тіла, точні кольори 36 палітр, прапорів та знаків. Перевірка розмітки зберігає велике зображення над словом; фактичний розмір 136/112 пікселів і вміщення вправи на екрані перевіряються окремо в браузері.
