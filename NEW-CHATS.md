# Як продовжувати проєкт у різних чатах

Усі файли сайту вже знаходяться в цій папці. Для роботи з кількох чатів додайте її до локального проєкту в Codex.

1. Створіть локальний проєкт із назвою **Word Cottage** у розділі проєктів застосунку.
2. Додайте кореневу локальну папку репозиторію Word Cottage до проєкту. У меню проєкту можна вибрати **Edit project / Редагувати проєкт**, потім **Add folder / Додати папку**. Зробіть цю папку основною (**Make primary**), якщо додано декілька папок.
3. Створюйте нові чати всередині цього проєкту — наприклад, «Етап 3», «Дизайн» або «Пошук слів».

У папці є `AGENTS.md` з інструкціями для Codex, `PROJECT.md` з описом поточного стану та `README.md` з описом сайту. Новому чату можна написати:

> Продовжуємо Word Cottage. Прочитай AGENTS.md і PROJECT.md у папці проєкту. Моє завдання: …

Чати працюватимуть зі спільними файлами. Кожен має свою історію розмови, тому важливі результати варто також зберігати в `PROJECT.md`. Для одночасної роботи давайте чатам різні частини проєкту або використовуйте окремі Git worktree, щоб вони не редагували один файл одночасно.

Щоб запустити локальний сайт, відкрийте `Start.cmd`. На іншому комп’ютері клонуйте цей GitHub-репозиторій і додайте його папку до Codex. Для подальших змін використовуйте commit і push; GitHub Actions автоматично оновлює GitHub Pages. Прогрес навчання з браузера автоматично не переноситься.

Якщо ви створюєте проєкт у вебверсії ChatGPT, він не отримує доступ до локальної папки автоматично: потрібне окреме підключення або завантаження файлів. Для прямого редагування цієї папки використовуйте локальний проєкт у застосунку.

Довідка: [офіційна документація OpenAI про проєкти та чати](https://learn.chatgpt.com/docs/projects?surface=app).
