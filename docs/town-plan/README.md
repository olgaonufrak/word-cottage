# Повний план піксельного містечка

Опублікована сторінка після розгортання: https://olgaonufrak.github.io/word-cottage/town-plan/.

План охоплює 3030 фіксованих карток, 102 розділи, 19 районів у 5 навчальних зонах, 629 автоматичних етапів до 5 карток та 18180 послівних кроків. Це проєкт повної гри, не реалізована кампанія. За оновленими правилами від 29 жовтня гра сама послідовно видає всі картки розділу. Кожна картка обов’язкова, S4 потребує N/N. Ручного відбору слів, вибору кількості та пошуку нових слів у грі немає; додавання особистих записів не входить у кампанію.

## Джерела

- `design.md` — основний план гри й послідовність реалізації.
- `progression-design.md` — формули, нагороди, повторення, збереження, сім прикладів сесій.
- `compatibility-notes.md` — точна сумісність із чинними навчальними механіками.
- `source-catalog.json` — точний знімок словників, ID, перекладів та контекстів.
- `catalog-summary.md` — повний порядок 102 розділів і підрахунки.
- `section-world-map.json` — 19 районів і 102 конкретні міські проєкти з S0, S1–S4 та R1–R3.
- `card-exercises.json` — усі послівні вправи, включно з відповідями й обмеженнями автоматичної перевірки. Це велика специфікація для розробки; сторінка завантажує вправи лише обраного розділу.
- `validation.json` — перевірка повноти останньої збірки плану.

## Відтворення

Запускати з кореня проєкту:

```text
node docs/town-plan/build-source-catalog.cjs
node docs/town-plan/build-section-map.cjs
node docs/town-plan/build-card-exercises.cjs
node docs/town-plan/build-plan.cjs
```

Перші три генератори використовують Node.js та наявні файли сайту. Останній використовує `marked` із доступного середовища документів; статичний сайт не потребує Node.js, npm, збірки чи сервера під час звичайного користування. Готові файли зберігаються у `dist/town-plan/`. Локально можна відкрити `dist/town-plan/index.html`; для реальної телефонної перевірки використовувати опубліковану HTTPS-адресу.

Генерація не змінює словники, навчальні скрипти чи прогрес. Після зміни джерел спочатку перевірити каталог, контексти, ID та підрахунки; будівельний план не має непомітно перейменовувати наявні картки. Варіанти з близькими значеннями потребують редакційної перевірки перед випуском гри: автоматичне виключення однакових перекладів не є повним семантичним аналізом усіх можливих відповідей.

## Вихідні матеріали

- `dist/town-plan/scenes/` — 45 зображень гри: по три сцени до кожного з 15 розділів плану, з переглядом на телефоні. Точні запити й відтворення галереї — у `visuals/README.md`.
- `dist/town-plan/index.html` — мобільна сторінка з пошуком усіх слів і проєктів.
- `dist/town-plan/full-plan.md` — весь текст плану та повний словниковий додаток.
- `dist/town-plan/all-words.csv` — точні ID, переклади, контексти, райони, проєкти й набори.
- `dist/town-plan/game-plan.json` — структурована кампанія.
- `dist/town-plan/card-exercises.json` — повна послівна специфікація вправ.
- `dist/town-plan/exercises/` — ті самі вправи, розділені на 102 файли для завантаження за запитом.

Сторінка не звертається до localStorage, особистих слів чи навчального прогресу. Усі навчальні джерела вже є частиною репозиторію; жодних користувацьких облікових даних у плані немає.
