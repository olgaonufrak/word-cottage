# Повна заміна 45 сцен

За прямим уточненням користувачки перероблено всі 45 активних зображень, а не лише одну мапу. Набір зберігає 15 розділів по три сцени, початкові ID, порядок, навчальний зміст і правила проходження. Повноекранний перегляд працює як раніше.

Використано вбудований imagegen: кожна сцена створена окремим викликом із новою просторою мапою як головним стилістичним орієнтиром. Після перегляду виправлено зайві фонові будинки, неправильні/пропущені лічильники та передчасно завершені споруди. Трійка 1/18 → 12/18 → 18/18 зберігає одну ділянку й ракурс.

- `STYLE.md` — спільна стилістична частина всіх запитів.
- `scene-notes.json`, `briefs.json` — точний зміст усіх 45 сцен.
- `chapters-01-04.json`, `chapters-05-08.json`, `chapters-09-12.json`, `chapters-13-15.json` — повні запити, уточнення, PNG-джерела й метадані нових JPEG.
- `baseline.json` — початковий стан галереї перед повною заміною.
- `integrate.cjs` — перевіряє 45 нових файлів і лише після цього оновлює канонічні записи; попередні версії зберігає в `previousVersions`.
- `redraw-audit.json` — для кожної сцени порівнює SHA-256 нового файла з попереднім: має бути рівно 45 змінених кадрів.
- `verification.json` — підсумок перевірки готових файлів.

Оригінали PNG і зведений `PROMPTS.md` збережені в папці візуалізацій цього чату `town-plan-open-pixel-v3`. До сайту входять JPEG `dist/town-plan/scenes/images/<id>-open-v3.jpg`. Перекодування не обрізає, не масштабує й не перемальовує зображення. Попередні файли залишені для історії; галерея показує 45 активних нових кадрів, а не всі історичні JPEG з папки.

Повторне застосування підготовлених метаданих із кореня репозиторію:

```text
node docs/town-plan/visuals/open-pixel-v3/integrate.cjs
node docs/town-plan/visuals/build-gallery.cjs
```

Інтеграція має захист від часткового оновлення. Вона вимагає всі 45 унікальних замін, нові версійні назви, PNG-джерела, точні запити та зміну кожного SHA-256 відносно початкового стану. Генератор галереї додатково вимагає `visualRevision: open-pixel-v3` у кожному активному записі. URL маніфесту та посилань з плану оновлені, щоб браузер завантажував нову галерею.

Словникові файли, навчальні механіки та браузерні сховища не змінюються.
