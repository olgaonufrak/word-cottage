# Word Cottage

Це основний локальний проєкт користувачки для вивчення англійської. Спілкуйся українською. Продовжуй роботу з наявними файлами; опис поточного стану міститься в `PROJECT.md`, інструкція запуску — у `README.md`.

## Файли та робота

- Статичний сайт у `dist/`: HTML, CSS і звичайний JavaScript, без npm та серверного застосунку. `Start.cmd` відкриває локальну копію.
- Спочатку перевір поточні файли та Git-стан. Зберігай зміни інших чатів і користувачки. Не перезаписуй проєкт старою копією чи архівом.
- Основні файли: `dist/app.js` — навчання та навігація; `dist/search.js` — пошук, особисті слова та словникові дані; `dist/data.js`, `dist/stage1-data.js`, `dist/stage2-data.js` — словники; `dist/style.css` — оформлення.
- Ідентифікатори слів уже використовуються для прогресу в localStorage. Зберігай наявні ID при зміні порядку карток або оформлення.
- Додані користувачкою слова та прогрес зберігаються в браузері. Папка містить код і навчальні словники, але не копію її браузерного прогресу.

## Узгоджена поведінка

- На вході рівно дві групи: «Слова на кожен день» та «Основа для початківця».
- У першій групі чотири етапи; Етапи 1 та 2 заповнені. Етапи 3 та 4 залишаються порожніми, доки користувачка не попросить їх заповнити.
- Назви тематичних розділів англійські; український підпис під ними — дрібним шрифтом та малими літерами.
- Вибір розділу відкриває повний список слів і перекладів. У ньому є позначки вибору та англійське аудіо, яке не змінює позначки. Унизу кнопка «Почати вчити».
- Далі кількість із кнопками −/+, варіанти 5/10/20, потім свайпи. Якщо слова позначені в списку, подальший набір обмежений ними. Без позначок доступний увесь розділ.
- Свайп вправо — вчити, вліво — пропустити. Навчання починається лише після набору обраної кількості. Вертикальний жест по картці не прокручує сторінку.
- Пошук знаходить слова з усіх словників та підтримує онлайн-пошук. Компактний результат із перекладом, транскрипцією й аудіо обох мов. Не повертай довгі визначення без запиту користувачки.
- Зберігай «Вивчені слова», повторення, навчання у двох напрямках і поточне оливкове оформлення.

## Перевірка й оновлення

- Для змін навчання використовуй відповідні перевірки з `checks/` через Node.js. Вони перевіряють логіку з імітованим DOM, а не реальний браузер чи звучання голосів. `checks/README.md` описує команди.
- Після зміни функцій або словників актуалізуй `PROJECT.md` і `README.md`.
- Користувачка обрала GitHub для збереження коду та GitHub Pages для публікації. Використовуй Git і GitHub, не використовуй Sites/ChatGPT hosting для подальших деплоїв. Не створюй нових архівів як основний спосіб збереження.
- Локальна папка залишається основою. Після авторизованих змін зроби commit і push у наявний GitHub-репозиторій, указаний в `origin`; не створюй інший репозиторій для кожного чату.
- `.github/workflows/pages.yml` перевіряє навчання та автоматично публікує тільки `dist/` після push у `main`. Публікація має завершитися успішно в GitHub Actions перед повідомленням про оновлений сайт. Pull request запускає перевірки без публікації.
- Не зберігай токени та облікові дані в документах, скриптах або архівах.
