# Word Cottage

Репозиторій: https://github.com/olgaonufrak/word-cottage

Сайт: https://olgaonufrak.github.io/word-cottage/

Для продовження роботи в різних чатах додайте цю папку як основну до локального проєкту Word Cottage у Codex. Кроки — у `NEW-CHATS.md`; поточний стан — у `PROJECT.md`, інструкції для Codex — у `AGENTS.md`.

Відкрийте `Start.cmd` подвійним кліком. Сайт відкриється у вашому браузері.
Також можна відкрити файл `dist/index.html` безпосередньо.

Встановлення програм і запуск сервера не потрібні. Усі файли сайту, зображення та 2580 навчальних карток збережені в цій папці. Папку можна переносити на інший комп’ютер.

## Що є на сайті

- На стартовій сторінці лише дві групи: «Слова на кожен день» та «Основа для початківця».
- У «Слова на кожен день» є чотири етапи. Етап 1 містить 29 тематичних розділів із 649 картками: словами, короткими фразами та парами антонімів з українським перекладом. Під англійською назвою кожного розділу є український підпис дрібним шрифтом. Етап 2 містить 29 розділів із 781 картками для щоденного спілкування, навчання, покупок та інших побутових ситуацій. Етап 3 містить 25 розділів із 750 картками — по 30 слів і коротких фраз у кожному. Теми охоплюють характер, здоров’я, побут, подорожі, культуру, технології, безпеку, природу, фразові дієслова та вирішення проблем. Порядок розділів відповідає списку користувачки; кожна картка має український переклад. Етап 4 поки порожній.

- 100 іменників, 100 дієслів, 100 прикметників і 100 найуживаніших слів.
- Картки з перекладом і навчанням в обох напрямках.
- Перед вибором кількості відкривається повний список слів розділу з перекладами. Позначте потрібні слова й натисніть «Почати вчити» внизу. Кількість і свайпи використовують тільки позначені слова; якщо позначок немає, доступний увесь розділ. Це також працює для «Моїх слів» і змішаного набору.
- Біля кожного слова в повному списку є кнопка ♫ для англійської вимови. Прослуховування не змінює позначки вибору.
- Відбір слів свайпами: вправо — вчити, вліво — пропустити. Навчання починається автоматично після вибору потрібної кількості слів. Також доступні кнопки та клавіші зі стрілками.
- Якщо слова закінчилися до набору потрібної кількості, можна переглянути пропущені або змінити кількість.
- Розділ «Вивчені слова» зі словами, позначеними кнопкою «Знаю».
- «Змішано» з вибором розділів, включно з особистими словами.
- Пошук англійською й українською серед усіх наявних слів та онлайн-пошук нових слів. Результат показує слово, переклад, транскрипцію IPA та озвучення обох мов без довгих визначень. Якщо транскрипції немає у словнику, показується повідомлення про її недоступність.
- Розділ «Мої слова»: додавайте знайдені слова, перевіряйте переклад і вивчайте їх на картках. Невідоме словнику слово можна додати вручну.
- Вибір кількості слів перед навчанням: кнопки «−» і «+» та швидкі варіанти 5, 10 і 20 слів.
- Повторення складних слів і позначення вивчених.
- Озвучення через голоси браузера або пристрою. Кнопки доступні для англійських і українських слів. Спочатку добирається голос відповідної мови: пріоритет мають голоси Google, потім Natural/Neural/Premium/Enhanced. Темп наближений до звичайного читання. Словниковий аудіозапис використовується, коли синтез мовлення недоступний. Набір і звучання голосів залежать від браузера та пристрою; це не пряме підключення до Google Перекладача. Доступність без інтернету залежить від установлених голосів.

## Прогрес

Прогрес зберігається в браузері локальної копії. Прогрес з онлайн-сайту автоматично сюди не переноситься. Щоб продовжувати навчання, відкривайте цю копію в тому самому браузері й не очищуйте його дані. Після перенесення папки в інше місце браузер може використовувати окреме сховище прогресу.

## Файли для редагування

- `dist/index.html` — сторінка сайту.
- `dist/style.css` — оформлення.
- `dist/data.js` — слова, переклади й розділи.
- `dist/stage2-data.js` — 29 розділів та словник Етапу 2.
- `dist/stage3-data.js` — 25 розділів та 750 карток Етапу 3.
- `dist/stage1-data.js` — 29 розділів та словник Етапу 1. Ідентифікатори карток залежать від розділу й англійського тексту; перестановка карток не змінює збережений прогрес.
- `dist/app.js` — логіка навчання.
- `dist/search.js` — пошук, онлайн-словник, переклад та збереження власних слів.
- `dist/patchwork.jpeg` — зображення оформлення.

Проєкт редагується локально, зберігається в GitHub і публікується через GitHub Pages.

## Локальна основа та онлайн-копія

Основний проєкт зберігається в цій локальній папці. Редагуйте файли в `dist/`, зберігайте зміни через Git commit і push у GitHub.

Workflow `.github/workflows/pages.yml` перевіряє навчання й автоматично публікує `dist/` у GitHub Pages після push у `main`. Для pull request виконуються тільки перевірки. Адреса опублікованого сайту відображається в GitHub: Settings → Pages і в результаті workflow.

Публікація використовує GitHub Actions, не потребує облікового запису ChatGPT для відвідування сайту й працює навіть коли комп’ютер вимкнений. Статус останньої публікації — у вкладці Actions репозиторію.

Прогрес навчання зберігається окремо в кожному браузері й на кожному пристрої; синхронізації прогресу між телефоном і комп’ютером немає.

## Онлайн-пошук і власні слова

Онлайн-пошук потребує інтернету. Транскрипція й доступні аудіозаписи надходять із Wiktionary через публічний API Wikimedia; автоматичний переклад — із MyMemory. У словників немає гарантовано повного покриття всіх слів англійської мови. Якщо слово не знайдено чи сервіс недоступний, його можна додати вручну з власним перекладом.

Перевіряйте автоматичний переклад перед додаванням: одне слово може мати кілька значень. Обраний переклад використовується на картках. Особисті слова й прогрес зберігаються в цьому браузері. Додані слова можна вивчати без інтернету; вони не синхронізуються з іншими пристроями.
